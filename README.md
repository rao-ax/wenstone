WenStone

Учебный проект по интернет-маркетингу на тему авторских браслетов из натуральных камней и дерева.

## Состав

- `WenStone_семантика_контент_план_Жао_Цзэюй.xlsx` содержит семантическое ядро, чек-лист сайта, план соцсетей, тексты постов и план видеохостинга.
- `site/dist/index.html` содержит статический прототип сайта для переноса в Tilda.
- `site/dist/404.html` содержит отдельную страницу 404.
- `site/dist/robots.txt` и `site/dist/sitemap.xml` подготовлены для индексации после публикации.

## Что нужно заменить перед реальной публикацией

- Подставить реальные ссылки на Telegram, VK и RuTube.
- Подключить Яндекс Метрику и Google Analytics с настоящими ID.
- Добавить опубликованную политику конфиденциальности и страницу согласия на обработку персональных данных.
- Если нужны реальные частотности, заменить учебные оценки в семантическом ядре данными из Яндекс Wordstat.
