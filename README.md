# WenStone
Учебный проект интернет‑маркетинга.
Сайт авторских браслетов из натуральных камней и дерева.

## О проекте
В состав сайта входят страницы:
- index.html — Главная
- catalog.html — Каталог изделий
- size.html — Подбор размера
- care.html — Уход за браслетами
- application.html — Форма заявки
- 404.html — Страница ошибки

## Локальный запуск
Скачайте все файлы, откройте index.html в браузере.

Проект опубликован через GitHub Pages.
